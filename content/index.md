# Garden Gate 🪴

This digital garden is a space for me to do as I please. Expect half-baked projects, partially formed thoughts, and potentially broken code. The main idea being pursued here is _play_, compiled and deployed in a place that is not private, not publicized—just shared. Typos and all.

While I'm not opposed to use of LLMs altogether and I definitely use them in my day-to-day work, this is a space for me. As such, I write the code and content. It's not meant to be showcase of my programming prowess, but the equivalent of a digital sketchbook. You're free to enjoy it, but it's not meant to be studied or graded. It just... is.
